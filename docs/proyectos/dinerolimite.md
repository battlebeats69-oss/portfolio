# DineroLimite

**Categoría:** Proyecto publicado en la [librería de RuleBug](https://rulebug.es/libreria).

## ¿En qué consiste?

Plataforma informativa de límites y normativa financiera de España, con contenidos de consulta y estructura web enfocada en indexación.

## Tecnologías y técnicas mostradas públicamente

Next.js, Supabase, serverless.
