# NULL_SIGNAL

**Categoría:** Proyecto publicado en la [librería de RuleBug](https://rulebug.es/libreria).

## ¿En qué consiste?

Experiencia narrativa interactiva que simula un sistema operativo ficticio. El jugador explora entornos, terminales y documentos como GHOST, dentro de una historia de infiltración.

## Tecnologías y técnicas mostradas públicamente

Vite, JavaScript, HTML y CSS.
